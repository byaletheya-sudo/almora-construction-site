# almoraconstruction.com

Static site for Almora Construction, served by GitHub Pages.

- Edit pages in `src/pages/`, shared header, footer and business details in `build.py`, styles in `assets/site.css`.
- Run `python3 build.py` to rebuild, then commit and push. Pages updates in about a minute.
- Hero video: Pexels video 17506765 ("An aerial view of a house being built"), Pexels license, free for commercial use, no attribution required. Re-encoded to 1280px H.264.
